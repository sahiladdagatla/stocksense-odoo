# 📦 StockSense

> A simple inventory and warehouse management system inspired by modern ERP platforms.

## 🚀 About the Project

StockSense is a warehouse and inventory management application designed to
manage products, stock movements, receipts, delivery orders, warehouses,
locations, and inventory operations from a centralized dashboard.

The project follows an Odoo-inspired inventory workflow while keeping the
interface simple and easy to use.

## ✨ Features

- 📊 Inventory Dashboard
- 📦 Product & Stock Management
- 📥 Receipts / Incoming Stock
- 📤 Delivery Orders / Outgoing Stock
- 🔄 Internal Stock Transfers
- 🏢 Warehouse Management
- 📍 Location Management
- 📜 Inventory Move History
- 🔎 Search and filtering
- 📋 List and Kanban views
- 🔢 Automatic operation references
- 👤 Responsible user tracking
- ⚠️ Low-stock / unavailable-stock indication
