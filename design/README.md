# StockSense UI design (Google Stitch export)

- `DESIGN.md`: **the design system to follow** (StockSense Executive Inventory: plum, teal, mint).
- `png/`: screenshots per screen. Layout reference. Several were generated with Stitch's blue
  "Alexandria" preset; their **colors are overridden by DESIGN.md** (plum), layout is kept.
- `screens/`: raw Stitch HTML/Tailwind exports. Reference only, not used at runtime.
- `alt-themes/`: other Stitch presets that came in the export. Not used.
